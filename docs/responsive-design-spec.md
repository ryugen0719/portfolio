# ポートフォリオサイト レスポンシブ対応仕様書

## 1. 目的

現行のデスクトップ版（無限キャンバス型ポートフォリオ）の世界観・レイアウト・操作感を維持したまま、タブレットおよびスマートフォンで閲覧・絞り込み・作品詳細閲覧を快適にする。

本仕様の対象はトップページ（`/`）である。レイアウトエディター（`/layout-editor`）は対象外とする。

## 2. 現状と対応方針

現行ページは、310 × 250px のセル、14px の間隔、7 列の繰り返しグリッドを、全画面の無限キャンバス上でドラッグ／ホイール操作する構成である。デスクトップではこの操作体験が作品表現の中心である一方、狭い画面では次の課題がある。

- 固定セルが画面幅を超え、作品の発見にドラッグ操作を要する。
- 作品名・説明がホバー時のみ見える。
- `body` とキャンバスが全画面固定で、一般的な縦スクロール閲覧ができない。
- 小さなフィルターボタンや BGM 操作がタップしづらい。

そのため、幅 768px 未満でも無限キャンバスを既定表示として維持し、必要に応じて「モバイル一覧モード」に切り替えられるようにする。幅 768px 以上では従来どおり無限キャンバスを表示する。

## 3. ブレークポイント

| 区分 | 画面幅 | 表示モード | 方針 |
| --- | ---: | --- | --- |
| デスクトップ | 1024px 以上 | 現行の無限キャンバス | **見た目・セル寸法・配置・操作・アニメーションを変更しない。** |
| タブレット | 768–1023px | 無限キャンバス | 310 × 250px セルとキャンバス操作を維持する。タッチ操作と固定 UI の当たり判定だけを補強する。 |
| 大型スマートフォン | 480–767px | 無限キャンバス（既定） | 現行のキャンバスを表示し、一覧へ切り替え可能にする。 |
| 小型スマートフォン | 320–479px | 無限キャンバス（既定） | キャンバスを既定表示とし、一覧は任意選択にする。切替ボタンは控えめに配置する。 |

表示は画面の向きではなく CSS ピクセル幅で判定する。横向きスマートフォンでも 768px 以上であれば、タブレット向けのキャンバスを表示する。スマートフォンではキャンバスを既定にし、控えめな固定ボタンから一覧へ切り替えられる。

## 4. デスクトップ固定要件

以下は幅 1024px 以上で変更禁止とする。

- 7 列グリッド、セル幅 310px、セル高 250px、セル間 14px。
- 初期表示時にブランドセルを中央に配置するカメラ位置。
- マウスホイール／ドラッグによる無限キャンバス、慣性移動、端部のぼかし表現。
- カテゴリー切替時の消失・出現アニメーション、背景粒子、ビネット、カスタムカーソル。
- 作品カードの画像トリミング、ホバー時オーバーレイ、文字サイズ、余白、色、ブランドセルの構成。
- 画面上部の左右ラベル、中央フィルター、右下 BGM、下部の探索ヒントの位置と見た目。
- 作品詳細ライトボックスのデスクトップ寸法・レイアウト。

実装時に共通スタイルを変更してデスクトップの見た目を変えてはならない。追加のスタイルは原則として `@media (max-width: 1023px)` および `@media (max-width: 767px)` に閉じる。デスクトップ用のコンポーネント分岐・DOM 構造も現状を維持する。

## 5. タブレット仕様（768–1023px）

### 5.1 キャンバスと操作

- 無限キャンバス、セルサイズ、作品配置、初期カメラ位置はデスクトップと同一とする。
- 指 1 本のドラッグでキャンバスを移動する。ドラッグ開始から 6px 超の移動時は、現行どおりカードのタップを無効化する。
- ホイール操作、慣性移動、カテゴリー絞り込みは現行どおりとする。
- 作品カードをタップすると詳細ライトボックスを開く。マウスが使える端末ではホバー表現も残す。
- カスタムカーソルは `hover: hover` かつ `pointer: fine` の環境のみ表示する。タッチ端末では表示しない。

### 5.2 固定 UI

- フィルターおよび BGM ボタンの操作領域は最小 44 × 44px とする。文字の見た目は現行を大きく変えず、透明な内側余白で領域を拡張してよい。
- フィルターは 1 行を保ち、横幅が足りない場合は横スクロール可能とする。スクロールバーは非表示でよい。
- 上部固定 UI はノッチ・ステータスバーと重ならないよう、`env(safe-area-inset-top)` を加算する。
- 右上の補助ラベルは表示を維持する。ただし幅不足時は「GAMES / 3D / WEB APPS」のテキストを非表示にし、罫線のみ残してよい。

## 6. モバイル一覧仕様（320–767px、任意切替）

### 6.1 ページ骨格

- `body` は縦スクロール可能にし、全画面固定・キャンバスの `touch-action: none` を解除する。
- 一覧モードでは、無限キャンバスの代わりに通常フローの `main` 要素内へ一覧を描画する。これにより、ブラウザ標準のスクロール、戻る操作、スクリーンリーダーの読み上げ順を利用できる。モバイルでの初期表示は無限キャンバスとし、利用者の操作で一覧へ切り替える。
- 背景色、粒子、グリッドテクスチャ、ビネット、金色アクセントは維持する。視認性と電池消費を考慮し、粒子数は 30 個以下とする。
- 初回ローディング演出は維持する。ただし表示中にスクロールを妨げない。

### 6.2 ヘッダーとフィルター

- ヘッダーはページ先頭に置き、スクロール時は `position: sticky` とする。背景には現行の上部グラデーションと十分な不透明度を付け、下のコンテンツが文字と重ならないようにする。
- 左側には `RYUGEN` と短い罫線を表示する。「ABOUT ME / CREATIVE WORK」と右側補助ラベルは非表示にする。
- BGM はヘッダー右端の 44 × 44px 以上のアイコンボタンにする。表示文言は視覚的には省略可能だが、`aria-label` は「BGMを再生」または「BGMを停止」とする。
- カテゴリーフィルターはヘッダーの次行に横 1 列で置く。`すべて / Blender / 写真 / Scratch / リンク / プロフィール` を現行と同じ順序・文言で表示し、横スクロール可能にする。
- 選択中のカテゴリは現行と同じ金色の下線と `aria-pressed="true"` で表す。選択後は一覧先頭へスクロールし、選択結果の見出しにフォーカスを移す。
- 「Scroll or drag to explore」ヒントは非表示にする。

### 6.3 コンテンツの並び

モバイル一覧では、空白セルと装飾専用セルを表示しない。すべてのカテゴリでは次の順に並べる。

1. ブランドセル（ロゴ、RYUGEN、DESIGN / CODE / IMAGE）
2. プロフィール
3. スキル、PC スペック、お気に入りアプリ、音声ビジュアライザー
4. 制作物（作品データの登録順）
5. SNS リンク
6. ステータス、カウントダウン、引用

カテゴリ選択時は、ブランドセルを先頭に残し、該当する要素のみを表示する。カテゴリーと対象は現行ロジックを踏襲する。

| フィルター | 表示対象 |
| --- | --- |
| すべて | 上記の全要素 |
| Blender | `Blender` タグを持つ制作物 |
| 写真 | `Photography` の制作物 |
| Scratch | `Scratch` の制作物 |
| リンク | SNS リンク |
| プロフィール | プロフィール、スキル、PC スペック、お気に入りアプリ、音声ビジュアライザー、ステータス、カウントダウン、引用 |

「該当なし」のときは、カテゴリー名と「表示できるコンテンツはありません。」を表示する。

### 6.4 各カード

- ページ左右余白は 16px、カード間隔は 12px とする。ノッチ／ホームインジケーターを考慮し、最下部には `env(safe-area-inset-bottom)` 以上の余白を設ける。
- 480–767px では作品カードを 2 列、320–479px では 1 列にする。2 列時もカード幅が 200px 未満になる場合は 1 列へ切り替える。
- 作品カードは画像の下に常時、作品名・最大 2 行の説明・タグを表示する。ホバーに依存して情報を隠さない。
- 作品画像は `aspect-ratio: 4 / 3`、`object-fit: cover` とする。画像領域と情報領域のいずれをタップしても詳細を開ける。
- ブランド、プロフィール、スキル、PC スペック、お気に入りアプリ、SNS、ステータス等の情報カードは 1 列で全幅表示する。ブランドセルは縦積みとし、ロゴ・コピーが 320px 幅でも重ならないこと。
- チップ・タグは折り返し可能にし、テキストを省略しない。英数字の長い文字列はカード外へはみ出さないこと。
- SNS リンクはカード全体を 44px 以上のタップ対象とし、外部リンクであることを視覚的およびアクセシブルな名前で伝える。

### 6.5 作品詳細ライトボックス

- タップした作品は全画面に近いモーダルで開く。外側余白は 12px、パネル最大高は `94dvh` とする。
- メディア領域は `52dvh` を上限、210px を下限とする。コンテンツは縦積みとし、説明・タグ・外部リンクが横に押し出されないこと。
- 閉じるボタンは右上に常時表示し、44 × 44px 以上とする。背景タップ、Escape（外部キーボード）、閉じるボタンで閉じられる。
- 開いたカードへは既存どおりフォーカスを戻す。モーダル表示中は背景を操作できず、必要に応じてフォーカストラップを設ける。

## 7. アニメーション・性能・アクセシビリティ

### 7.1 アニメーション

- `prefers-reduced-motion: reduce` では、読み込み、カテゴリ切替、背景、星、カード、カーソルを即時または静的表示にする。既存の方針を一覧モードにも適用する。
- モバイルのカテゴリ切替は 200ms 以下のフェードのみとし、キャンバス用の 1.5 秒のブラー遷移は使わない。
- `hover` 専用の演出は、タップ操作の必須情報・操作にしない。

### 7.2 アクセシビリティ

- すべての操作要素は最小 44 × 44 CSS px の当たり判定を持つ。
- キーボードでフィルター、カード、SNS、BGM、モーダルの順に到達できる。`focus-visible` は現行の金色アウトラインを維持する。
- モバイル一覧の DOM 順は視覚順と一致させる。CSS の並べ替えだけで意味順を変えない。
- 画像には作品名を含む代替テキストを設定する。装飾用の粒子・罫線・空白セルは読み上げ対象にしない。
- 文字のコントラストは通常テキストで WCAG 2.2 AA（4.5:1）を満たす。淡色の補助文言を使う場合も背景とのコントラストを検証する。

### 7.3 性能

- モバイルでは画面外の画像を遅延読み込みし、`sizes` を 1 列／2 列の実表示幅に合わせる。
- 背景粒子数を削減し、カードの大量な `backdrop-filter`、ぼかし、連続アニメーションを避ける。
- 初回表示、フィルター切替、作品詳細の操作中に、スクロールの引っ掛かりや 300ms を超える入力遅延を生じさせない。

## 8. 実装範囲と設計指針

| 対象 | 実装方針 |
| --- | --- |
| `app/page.tsx` | 768px 未満では無限キャンバスを初期表示し、一覧へ任意切替できるようにする。768px 以上の既存キャンバス分岐は変更しない。カテゴリ状態、BGM 状態、作品詳細状態、既存データを両モードで共有する。 |
| `app/components/InfoBlocks.tsx` | 作品カードを一覧表示でも利用できるよう、モバイル向けの常時表示情報と適切な代替テキストを追加する。既存のデスクトップ用カード出力は変更しない。 |
| `app/globals.css` | モバイル一覧用スタイルと、スマートフォンでキャンバス既定表示時の控えめな切替 UI を追加する。デスクトップの既存セレクター値を変更せず、幅上限付きメディアクエリで上書きする。 |
| `app/data.tsx` | コンテンツと順序の唯一の情報源として維持する。モバイル用に作品・情報・SNSを別管理しない。 |

SSR と初回ハイドレーションの表示差を避けるため、画面幅に依存する分岐はクライアントで確定するまでプレースホルダーを表示するか、CSS による安全な表示切替と組み合わせる。画面回転・リサイズ時には 768px 境界を再評価し、選択済みカテゴリと開いている作品詳細を保持する。

## 9. 受け入れ基準

### デスクトップ

- 1440 × 900px および 1920 × 1080px のスクリーンショット比較で、現行とセル寸法、配置、固定 UI、初期カメラ位置に差分がない。
- マウスドラッグ、ホイール、慣性、ホバー、カテゴリー切替、BGM、作品詳細が現行どおり動作する。

### タブレット

- 768 × 1024px、820 × 1180px、1024 × 768px で、キャンバスを指で移動でき、カードのタップとドラッグが競合しない。
- 上部フィルターと BGM がノッチや画面端に隠れず、すべてタップできる。

### スマートフォン

- 320 × 568px、375 × 667px、390 × 844px、430 × 932px、768 × 1024px で横スクロールが発生しない。
- 初期表示は無限キャンバスであり、一覧への切替・キャンバスへの復帰が可能である。
- 一覧モードでは、すべてのカテゴリで該当コンテンツが表示され、フィルター後に一覧先頭へ戻る。
- 作品名・説明・タグがホバーなしで読め、作品カード、SNS、BGM、閉じるボタンを片手でタップできる。
- 作品詳細は画像・説明・タグ・外部リンク・閉じるボタンを縦スクロールで到達可能である。

### 共通

- `prefers-reduced-motion` 有効時に、必要以上の動きが残らない。
- キーボード操作、フォーカス移動、モーダルを閉じたあとのフォーカス復帰を確認する。
- Chrome / Safari の最新 2 バージョン、および iOS Safari / Android Chrome の実機または同等エミュレーションで確認する。
